# Synthetic research thesis

*Listening to Imaginary Rivers: Sensor Placement in Simulated Branching Networks* is an original fictional PhD-style document for demonstrating source navigation and a writing workflow. Its named author Mira Fenwick, laboratory, networks, measurements, and numerical results are invented. It does not report a real experiment, institution, field campaign, or published study.

Read the retained [PDF](synthetic-thesis.pdf), or open [main.tex](main.tex) in the extension's [isolated demonstration](../../docs/demo.md). The example uses ordinary LaTeX headings and captions; no USCthesis files, external artwork, font files, or bibliography entries are included.

## Source conventions

The fixture mixes short and long titles, repeated titles under different parents, four-level branches, and long captions. These are navigation cases, not parser size limits.

- Each heading or caption occupies one line and has a unique `demo-` label on that line.
- Headings use `chapter`, `section`, `subsection`, and `subsubsection`; captions occur in figure or table environments.
- Titles are plain printable ASCII without nested TeX markup. Root inputs are literal paths under `chapters/`.
- Standard `report` numbering supplies chapter-local figure/table counters and one `appendix` transition.

Edit canonical `.tex` files rather than a second outline representation. The extension parses these sources directly. Front matter generated by TeX is not part of the 54-heading source outline. This controlled example does not establish support for arbitrary macro-generated headings or exact PDF numbering; see [the backend limits](../../docs/backend.md#unsupported-constructs-and-compatibility-limits).

## Compile the reading copy

Compilation is optional for using LaTeX TOC. To rebuild the PDF, install a standard TeX distribution providing `latexmk`, `pdflatex`, `report`, `fontenc`, and `geometry`. From this directory:

```sh
latexmk -norc -pdf -pdflatex='pdflatex -no-shell-escape %O %S' -interaction=nonstopmode -halt-on-error -outdir=build main.tex
```

This lets `latexmk` perform the passes needed for contents, lists, and labels. It ignores local/global `latexmk` configuration and disables shell escape. The source needs no network access, downloaded assets, or bibliography tool.

Review `build/main.pdf` before replacing `synthetic-thesis.pdf`. Keep only that retained PDF as the public reading copy: `build/`, logs, auxiliary files, recorder files, and SyncTeX output are excluded by the local `.gitignore`. The retained PDF is a snapshot, not an automatic live build; editing a source does not update it.
